# ♾️ GritMath

**GritMath** is a high-performance, native speed-math application designed to train mental arithmetic with raw speed and precision. Built on React Native and Expo, featuring a custom Math Engine, interactive Glassmorphism UI, and offline capabilities.

## 🚀 Features
- **Dynamic Math Engine:** Instantly generates limitless math questions (Fractions, Squares, Cubes, Arithmetic).
- **Infinite Training Mode:** Non-stop, TikTok-style vertical reels of math problems.
- **Deep Glassmorphism UI:** Premium Apple-style frosted glass UI with smooth, fluid animations.
- **Offline Native Execution:** Fully bundled Release APK for zero-latency math practice.

## 🛠 Tech Stack
- **Framework:** React Native / Expo
- **State Management:** Zustand
- **Storage:** MMKV (Ultra-fast synchronous storage)
- **Styling:** Custom CSS/Theme system with Expo Blur
- **Icons:** Feather Icons
